# DevMentor UI

Before building or changing a screen, read [the design system guide](docs/design-system.md), then the linked Storybook component documentation and screen state map. The approved scope and decisions are in [POSTEP.md](POSTEP.md).

Follow the repository root AGENTS.md architecture/testing rules. Public components are Tailwind-only; signed-in/backend components use the existing Base UI primitives (Q1(a), F3). Keep changes within the approved plan; record missing components instead of adding unapproved variants or dependencies (prompt rule 6).
