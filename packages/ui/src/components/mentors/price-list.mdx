# Price list

`import { PriceList } from "@devmentor/ui/components/mentors/PriceList"`

E02 product component for the public profile `/mentors/[id]` (Flow 2 step 4). Public kit only (F3).

## 1. What it is for

It shows what one session costs in each format before the mentee picks a slot (D06, R01).

## 2. When to use

- On `/mentors/[id]`, once.

## 3. When not to use

| Situation | Use instead |
|---|---|
| The mentor editing prices | the profile form on `/mentor/profile` |
| Checkout and receipts | E04 |

## 7. Behaviour and accessibility

- A plain list; screen readers hear "Prices, list, 2 items".
- Prices are never constrained against each other (E02 Flow 2).

## 8. Content

- The page formats amounts with core's `formatMoney` (P17): `$40` without `.00`, cents kept when
  they exist (`$1.40`). The component does not format money, because `ui` may not import `core`.
- USD only (MD2); no currency code is shown.
- No "/month", plans or "Most popular" (A05).
