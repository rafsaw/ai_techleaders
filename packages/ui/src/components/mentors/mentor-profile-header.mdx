# Mentor profile header

`import { MentorProfileHeader } from "@devmentor/ui/components/mentors/MentorProfileHeader"`

E02 product component for the public profile `/mentors/[id]` (Flow 2 step 4). Public kit only (F3).

## 1. What it is for

It tells a mentee who the mentor is and what they help with: the display name, one area and the
mentor's own plain description. That is all a mentee judges by, together with the links to
public work (N02).

## 2. When to use

- At the top of `/mentors/[id]`, once per page.

## 3. When not to use

| Situation | Use instead |
|---|---|
| A row in the E03 listing | a dense list row (R01.1), built with E03 |
| The signed-in account's own name | `AccountSummary`, `SiteHeader` |

## 4. Anatomy

| Part | Required | Notes | Source |
|---|---|---|---|
| Display name | yes | `h1`, `text-page-title`; the account's `users.name`, not a profile field | E02 Flow 2 |
| Area pill | yes | one of *TypeScript*, *React*, *Python*; outline pill, the outline Badge look in plain Tailwind | MD3, Q3, B5; P-PP1, proposal approved by Rafał |
| Description | yes | `text-body`, `max-w-text`, line breaks kept (`whitespace-pre-line`) | E02 Flow 2 |

Name and pill sit on one line and wrap below each other when there is no room; the description
is under them (P-PP2, proposal approved by Rafał).

## 5. Variants

None. The area changes only the pill text.

## 6. States (data states)

| State | Story |
|---|---|
| Default | *Playground* |
| Each area | *Areas* |
| Markdown or HTML typed by the mentor | *Plain text only* |
| No ratings | *No ratings* |
| Long name and unbroken words, 320 px | *Long content, narrow* |
| Loading, error | not applicable: the page renders on the server; a missing profile is a 404 (E02 Flow 2) |
| Empty, partial | not applicable: name, area and description are required (E01 data model, E02 Flow 2) |
| Many | not applicable: one area per mentor (MD3) |

## 7. Behaviour and accessibility

- The name is the page's only `h1`. The wrapper is a `<div>`, not `<header>`: outside `<main>` a
  `<header>` becomes a second banner landmark next to `SiteHeader` (found by the a11y test, WCAG 1.3.1).
- The area is text, so it does not rely on colour (WCAG 1.4.1).
- The description is a text node: Markdown and HTML show as typed and are never rendered (E02 Flow 2).

<Canvas of={Stories.PlainTextOnly} />

## 8. Content

- The description is the mentor's own words; the product adds nothing to it.
- Area names are written *TypeScript*, *React*, *Python* (D04).
- Nothing about ratings, titles, employers or years next to the name (N02, A03, A08).

## 9. Responsiveness

| Width | Behaviour |
|---|---|
| 320 px | a long name or word breaks anywhere; the pill moves under the name |
| 768 px, 1440 px | the description stays within `max-w-text` |

| Do | Don't | Why |
