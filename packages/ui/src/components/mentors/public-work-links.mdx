# Public work links

`import { PublicWorkLinks } from "@devmentor/ui/components/mentors/PublicWorkLinks"`

E02 product component for the public profile `/mentors/[id]` (Flow 2 step 4). Public kit only (F3).

## 1. What it is for

It shows what the mentor has built, in place of ratings (N02, R01.7). People choose by what
someone made, not by scores (41 of 54 in the survey, R01.7).

## 2. When to use

- On `/mentors/[id]`, under the profile header.

## 3. When not to use

| Situation | Use instead |
|---|---|
| A link inside the product | `LinkButton` with `variant="link"` |
| The mentor's own public page link on `/mentor` | `BookableStatusLine` |

## 4. Anatomy

| Part | Required | Notes | Source |
|---|---|---|---|

None.

<Canvas of={Stories.Many} />

## 7. Behaviour and accessibility

- Each link opens in a new tab with `rel="nofollow noopener ugc"` (E02 Flow 2): the content is the mentor's, not ours.
- The accessible name ends with "(opens in a new tab)" (E02 UI/UX).
- Links keep the order the mentor typed.

## 8. Content

- The label is the hostname plus path. Query and fragment are left out, and a site root shows the
  hostname only (P-PP4, proposal approved by Rafał: the spec says "hostname plus path" and does not cover these cases).
- The `href` is always the full URL the mentor saved.

## 9. Responsiveness

| Width | Behaviour |
|---|---|

| 768 px, 1440 px | one link per row |

## 10. API

| Prop | Type | Description |
|---|---|---|
| `links` | `string[]` | 1–5 absolute `https:` URLs |

`linkLabel(url)` returns the visible label.

## 11. Code

```tsx

```

## 12. Do and don't

| Do | Don't | Why |
|---|---|---|
| Show where a link goes (hostname plus path) | "Link 1", "GitHub" | the mentee judges by the work (N02) |
| Say that it opens a new tab | open a new tab silently | E02 UI/UX |
