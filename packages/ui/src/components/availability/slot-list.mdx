# Slot list

```tsx
import { SlotList } from "@devmentor/ui/components/availability/SlotList"
import { SlotRow } from "@devmentor/ui/components/availability/SlotRow"
```

E02 product component for *Upcoming slots* on `/mentor/slots` (Flow 4), signed-in kit: a dense
list of rows (R01.1, R01.3), not cards.

## 1. What it is for

It shows a mentor the times mentees can book, which ones are taken, and lets them withdraw an
open one safely.

## 2. When to use

- `/mentor/slots`, below the *Add a slot* form.

## 3. When not to use

| Situation | Use instead | Source |
|---|---|---|
| Records to compare by column | `Table` / `DataTable` | table.mdx |
| Public slot picking (E04) | not built yet (What is missing) | Q6 |

## 4. Anatomy

| Part | Notes |
|---|---|
| Heading *Upcoming slots* | level 2 |
| `SlotRow` | start (`children`, the page's `LocalTime`), `text-row-title`, `tabular-nums`; metadata line: zone · *Reserves 50 minutes; the mentee picks 25 or 50* |
| State | badge *Open* (`outline`) or *Booked* (`secondary`) |
| **Remove** | open rows: small destructive button → alert dialog *Remove the slot on …?* |
| Booked sentence | booked rows, instead of Remove (E02 Flow 4 step 3) |

## 5. Variants

Rows: open (with Remove) and booked (with the sentence).

## 7. Behaviour and accessibility

- A `section` named by its heading; rows are a list; lines between rows (`divide-y`).
- Remove follows the Delete confirmation pattern: the question names the slot, focus starts on **Cancel**, Escape closes (Alert dialog).
- The row disappears only after the server confirms (Q4); a 409 or 404 keeps the dialog open with the
  reason and only **Close**; any other error (no network, 500) keeps **Remove slot** for a retry (P-DC1,
  proposal approved by Rafał; Patterns/Delete confirmation).
- Loading is announced once (`role="status"`, `aria-busy`).

## 10. API

|---|---|---|
| `SlotList` | `count`, `loading?`, `error?`, `onRetry?`, `children` | the section and its states |

## 11. Code

```tsx
<SlotList count={slots.length}>
  {slots.map((slot) => (
    <SlotRow key={slot.id} timeZone={zone} booked={slot.booked}
      remove={() => apiCall(`/api/availability/slots?id=${slot.id}`, { method: "DELETE" })}>
      <LocalTime iso={slot.startsAt} />
    </SlotRow>
  ))}
</SlotList>
```
