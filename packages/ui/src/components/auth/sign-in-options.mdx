# Sign-in options

`import { SignInOptions } from "@devmentor/ui/components/auth/SignInOptions"`

E01 product component for `/sign-in`, built from the public kit (F3) only: `LinkButton`,
`Notice`, `SchemaForm`, `SubmitButton`.

## 1. What it is for

It lets a visitor sign in the way the product prefers (GitHub first) or with email, and tells
them plainly why a previous attempt failed.

## 2. When to use

- `/sign-in` only (E01 UI/UX). Phase 1: GitHub only (no `email` prop); Phase 2: with the email form.

## 3. When not to use

| Situation | Use instead | Source |
|---|---|---|
| Creating an account | `/sign-up` with `SchemaForm` (stage 3 screen) | E01 Flow 2 |
| The invitation page | `InvitationPanel`, which links here with `returnTo` | E01 Flow 3 |

## 7. Behaviour and accessibility

- Tab order: GitHub, email, password (and its toggle), **Sign in**, **Create an account** (story *Playground* tests GitHub first).
- Banners: failures `role="alert"`, the cancel note `role="status"`.
- After `email_not_confirmed`, **Resend confirmation** re-posts the same email and password (E01: only the person who knows the password can trigger a link). A later successful or different failure removes it.
- No password-reset link (N03).

## 8. Content

All copy from `2026-10-17-accounts-and-roles.md` except the `github_no_verified_email` wording

## 10. API

| Prop | Type | Description |
|---|---|---|
| `githubHref` | `string` | `/api/auth/github` with the validated `returnTo` |
| `error` | `string?` | `?error=`; unknown codes show nothing |
| `email` | `{ schema, signIn, resend, onSignedIn, signUpHref }?` | Phase 2; `signIn` and `resend` are `apiCall`s |

<Controls of={Stories.Playground} />

## 11. Code

```tsx
<SignInOptions
  githubHref={`/api/auth/github?returnTo=${encodeURIComponent(returnTo)}`}
  error={searchParams.error}
  email={{
    schema: signInSchema.pick({ email: true, password: true }),
    signIn: (values) => apiCall("/api/auth/sign-in", { method: "POST", body: { ...values, returnTo } }),
    resend: (values) => apiCall("/api/auth/confirm-email/resend", { method: "POST", body: values }),
    onSignedIn: (to) => window.location.assign(to),
    signUpHref: `/sign-up?returnTo=${encodeURIComponent(returnTo)}`,
  }}
/>
```

## 12. Do and don't

| Do | Don't | Why |
|---|---|---|
