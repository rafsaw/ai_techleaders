# Separator

`import { Separator } from "@devmentor/ui/components/separator"`

shadcn `base-nova` separator (Base UI `Separator`) in the `border` colour.

## 1. What it is for

A separator draws a thin line between parts of one panel, so the user sees where one group
ends without a new card or a shadow.

## 2. When to use

- Between sections of one panel (display name and sign-in methods on `/account`, E01).
- Between list rows use `divide-y divide-border` on the list (R01.3, Z4, C1); a `Separator` element is for one-off lines.

## 3. When not to use

| Situation | Use instead | Source |
|---|---|---|
| Separating rows of a list | `divide-y divide-border` on the list | R01.3, Z4 |
| Separating two unrelated parts of a page | spacing: `gap-component` or `gap-section` | T4 |
| Making a group stand out | a heading (type role), not a heavier line | R01.5, Z2 |

## 4. Anatomy

One part: a 1 px line in `--border` (`h-px` horizontal, `w-px` vertical).

## 5. Variants

| Orientation | When |
|---|---|
| `horizontal` (default) | between stacked sections |
| `vertical` | between items in one row (rare; a middle dot `·` in text is usually enough, R01.1) |

<Canvas of={SeparatorStories.Orientations} />

## 6. States

None: a separator is not interactive. The line is below 3 : 1 on purpose (exception T7:
decorative; sections are recognised by their text, WCAG 1.4.11).

<Canvas of={SeparatorStories.States} />

## 7. Behaviour and accessibility

- Base UI renders `role="separator"` with `aria-orientation` (story *Playground* tests it). Screen readers may announce it as a separator.
- Never put meaning only in the line: every section has its own label or heading (WCAG 1.3.1).
- Not focusable.

## 8. Content

No text. A labelled divider (*or*) is `FieldSeparator` in forms.

## 9. Responsiveness

A horizontal separator spans its container at every width; a vertical one takes the height of
its row.

## 11. Code

```tsx
<Separator />
```

From the product (`/account`, between the name form and the sign-in methods):

```tsx

  <DisplayNameForm />
  <Separator />
  <SignInMethods />

```

## 13. Related

- Used in: `AccountSummary` (stage 3), list rows (via `divide-y`).
