# How to choose

Choose by the user's task, then check availability. **Missing** means the component is
not approved for this release: use the stated existing alternative and record the need
on [What is missing](?path=/docs/design-system-what-is-missing--docs), rather than adding
it during screen work (POSTEP: scope and omitted primitives; prompt rule 6).

Sources: `R*` and `A*` refer to `lekcja-06/referencje.md`; `Z*` to `lekcja-06/tokeny.md`;
`P-*` are proposals approved by Rafał in `packages/ui/POSTEP.md`. E01 and E02 refer to
the account and mentor-setup specifications in `.ai/specs/`. APG means the
[WAI-ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/patterns/).
