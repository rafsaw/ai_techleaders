# Usage and accessibility

Use the component's documented keyboard behaviour and the existing form/pattern wiring.
An accessibility addon pass is one check; focus order, meaningful text and actual task
completion still need browser inspection (prompt stages 2 and 5).

`P-*`, `B*`, `Q*` and F2/F3 below resolve to the approved decisions in `packages/ui/POSTEP.md`;
E01/E02 are `.ai/specs/implemented/2026-10-17-accounts-and-roles.md` and
`.ai/specs/2026-10-18-mentor-setup.md`. WCAG references use
[WCAG 2.2](https://www.w3.org/TR/WCAG22/); overlay behaviour follows
[APG Alert Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/alertdialog/).

is never authorization (E01 access control; E02 MD11).
