# What to avoid

Use this page while reviewing a screen and its diff. References `R*`, `A*`, `K*` resolve
to `lekcja-06/referencje.md`; `T*`, `Z*`, `C*` resolve to `lekcja-06/tokeny.md`.

## Generic AI appearance

  <thead><tr><th scope="col">{"Recognize on screen and in code"}</th><th scope="col">{"Why it causes a problem"}</th><th scope="col">{"Replace with"}</th><th scope="col">{"Source"}</th></tr></thead>
  <tbody>
    <tr><td>{"Gradients on a page, text or button; gradient utilities or "}<code>{"linear-gradient"}</code></td><td>{"Reintroduces the rejected effects-led AI landing-page style."}</td><td>{"Semantic background, foreground and primary roles."}</td><td>{"A01; Z5, T1"}</td></tr>
    <tr><td>{"Glass panels and blur; translucent card surfaces or "}<code>{"backdrop-blur"}</code></td><td>{"Replaces readable warm surfaces with decorative effects."}</td><td>{"Opaque "}<code>{"card"}</code>{"/"}<code>{"popover"}</code>{" surfaces.     <tr><td>{"Glow and luminous coloured shadows; "}<code>{"drop-shadow"}</code>{" or custom decorative "}<code>{"box-shadow"}</code></td><td>{"Draws attention through effects rather than content hierarchy."}</td><td>{"Typography and borders; "}<code>{"shadow-overlay"}</code>{" only for the approved overlay layer."}</td><td>{"A01; Z2; P-S1"}</td></tr>
    <tr><td>{"Emoji as icons, sparkles as \u201cAI\u201d; emoji in headings or "}<code>{"Sparkles"}</code>{" imports"}</td><td>{"Recreates the explicitly rejected visual vocabulary."}</td><td>{"Text; use the current consistent icon set only when an icon serves a task."}</td><td>{"A01; R02.5; Foundations/Icons approved starting set"}</td></tr>

The code fragments above are search clues, not proof by themselves: a legitimate
layout can have three columns and a decorative icon can be hidden from a screen reader.
Judge the actual user task and cited rule (A01's signatures; WCAG 1.1.1).

## Implementation mistakes

<table tabIndex={0} aria-label="Implementation mistakes" className="focus-visible:outline-solid focus-visible:outline-2 focus-visible:outline-ring focus-visible:outline-offset-2">
  <thead><tr><th scope="col">{"Recognize on screen and in code"}</th><th scope="col">{"Why it causes a problem"}</th><th scope="col">{"Replace with"}</th><th scope="col">{"Source"}</th></tr></thead>
  <tbody>
    <tr><td>{"A raw colour, palette class or arbitrary Tailwind value in a component"}</td><td>{"Bypasses documented roles, contrast and theme behaviour."}</td><td>{"Existing semantic token; request approval when a role is genuinely absent. Run "}<code>{"npm run check:tokens"}</code>{"."}</td><td>{"prompt rule 3; Z6; T1\u2013T8"}</td></tr>
    <tr><td>{"A new variant/dependency introduced \u201cwhile here\u201d; unexplained variant keys or package changes"}</td><td>{"Expands the approved system without a screen requirement."}</td><td>{"Existing API, or record the unmet requirement on What is missing."}</td><td>{"prompt rule 6; B5"}</td></tr>
    <tr><td>{"A clickable "}<code>{"div"}</code>{"/"}<code>{"span"}</code>{" or navigation button with no actual link"}</td><td>{"Loses native keyboard/link behaviour and semantics."}</td><td>{"Native button for action, anchor for navigation."}</td><td>{"WCAG 2.1.1, 4.1.2; POSTEP Link as Button decision"}</td></tr>
    <tr><td>{"Placeholder as the only name; no visible label/association"}</td><td>{"The field becomes unidentified while typing."}</td><td>{"Visible label plus optional example placeholder and associated hint/error."}</td><td>{"WCAG 1.3.1, 3.3.2; F2, Q-CF1"}</td></tr>

    <tr><td>{"Disabled submit with no reason, or faded text via opacity"}</td><td>{"People cannot recover; text may lose contrast."}</td><td>{"Visible explanation, approved disabled tokens and a clear prerequisite action."}</td><td>{"B2; E02 MD10; WCAG 3.3.2"}</td></tr>
