# Content

Speak directly, without marketing, as in the interviews. DevMentor helps someone resolve
a specific blocker in a booked text session; it does not sell a learning journey or promise
an immediate answer (POSTEP Q5 tone approval; brief D01, D03, D16; A02, A07).

References `A*`/`R*` are from `lekcja-06/referencje.md`. `P-*` are proposals approved by
Rafał in `packages/ui/POSTEP.md`; E01/E02 are the account and mentor-setup specs in `.ai/specs/`.
Example amounts and dates below are fictional formatting examples, not claims about customers.

Do not claim success because a request started or because Stripe redirected back.
Show saved/ready copy only after the server confirms it (Q4; E02 MD7, MD9).
Use [Usage and accessibility](?path=/docs/design-system-usage-and-accessibility--docs)
for field associations and announcements (WCAG 3.3.1, 4.1.3).
