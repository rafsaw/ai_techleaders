# Shape and depth

Shape is chosen by **role**. Content is separated by thin lines and surfaces, not by shadows
(R01.3, Z4).

## Borders

| Use | Class | Source |
|---|---|---|
| Separator between list rows | `divide-y divide-border` | R01.3, Z4 |
| Panel edge | `border border-border` | R01.3 |
| Field outline | `border border-input` (3 : 1) | T5, WCAG 1.4.11 |
| Focus | `outline-2 outline-solid outline-offset-2 outline-ring`: full colour, 2 px, 2 px away from the edge; no translucent glow | B3 (proposal approved by Rafał), T5, WCAG 2.4.7 |
| Error | `border-destructive`, no glow; the message is text below the field | B3, WCAG 3.3.1, 1.4.1 |

## Shadows

<Unstyled>
  <TokenTable
    rows={[
      { token: "--shadow-overlay", utility: "shadow-overlay", use: "menu, popover, dialog: layers that float above the page", source: "P-S1, proposal approved by Rafał; the value is a start value" },
    ]}
  />
</Unstyled>

| Rule | Source |
|---|---|
| No shadow on list rows or cards; a card is separated by its border and surface. | R01.3, Z4 |
| A shadow is used only for layers that float above the page (menu, popover, dialog), with `shadow-overlay`. | P-S1, proposal approved by Rafał |
| A shadow is never the only thing that separates content: overlays also have a border. | P-S1, prompt (What to avoid) |
