# Shape and depth

Shape is chosen by **role**. Content is separated by thin lines and surfaces, not by shadows
(R01.3, Z4).

|---|---|

## Borders

| Use | Class | Source |
|---|---|---|
| Separator between list rows | `divide-y divide-border` | R01.3, Z4 |
| Panel edge | `border border-border` | R01.3 |
| Field outline | `border border-input` (3 : 1) | T5, WCAG 1.4.11 |
| Focus | outline in `ring`, at least 2 px | T5, WCAG 2.4.7 |

## Shadows

| Rule | Status |
|---|---|
| No shadow on list rows or cards; a card is separated by its border and surface. | R01.3, Z4 |
| A shadow is used only for layers that float above the page (menu, popover, dialog). | Proposal P-S1 |
| A shadow is never the only thing that separates content. | prompt, What to avoid |
