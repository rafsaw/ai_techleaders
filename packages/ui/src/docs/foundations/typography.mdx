# Typography

Two typefaces: **Geist** for the interface and **Geist Mono** for code. Both are start values;
the choice of typeface is still open (Q4, gap in R01–R02). Fonts are bundled through
`@fontsource-variable/geist` and `@fontsource-variable/geist-mono`, never loaded from a CDN.
The Next.js app keeps loading Geist through `next/font` (Z-5).

## Rules

| Rule | Source |
|---|---|
| Components and screens use a **type role** (`text-page-title`, `text-body` …), never a size class (`text-sm`, `text-2xl`). | proposal approved by Rafał 2026-10-21 |
| Hierarchy by size and weight, never by colour. | R01.5, Z2 |
| A list row has a title in `text-row-title` and one metadata line in `text-meta text-muted-foreground`. | R01.1, R01.5, C1 |
| `font-mono` only for code, file names, paths and configuration. Never for headings, metadata or labels. | R01.2, Z3 |
| Prices and times use tabular figures (`tabular-nums`) so columns line up. | Q4 |
| Running text is at most about 65 characters per line (`max-w-text`). | P-L4 (proposal approved by Rafał), WCAG 1.4.8 (AAA, advisory) |

## Roles

Each role is a token in `globals.css` (`--text-<role>`, with its line height and weight), so
one class sets size, line height and weight together.
