# Color

DevMentor is warm grey with no accent colour. Hierarchy comes from type size and weight, not
from colour (R01.5, Z2). Colour is never the only carrier of meaning: every status also has
text or an icon (Q2, WCAG 1.4.1).

## Rules

| Rule | Source |
|---|---|
| Use only the semantic classes below (`bg-card`, `text-muted-foreground`, `border-input` …). Raw `--warm-*`, `--red-*`, `--green-*`, `--amber-*` live only in `globals.css`. | Z6, prompt rule 3 |
| Neutrals are warm greys, hue 70°. No cool greys. | R01.4, T1 |
| There is no accent colour yet. `primary` is near-black (light) or near-white (dark). | gap in R01–R02; T1 |
| Purple and indigo are never an action colour, in gradients or solid. | A01, PO 2026-10-21 |
| One `primary` button per screen. | R01.6, Z1 |
| `destructive` only for errors and irreversible actions. Not for warnings or emphasis. | T5, Q2 |
| `success` and `warning` are status roles. A status always shows text or an icon too. | Q2, WCAG 1.4.1 |
| `accent` is the hover surface, not a brand colour. | tokeny.md |
| `border` is a decorative separator (below 3 : 1 by design). Field outlines use `input`. | R01.3, T5, T7, WCAG 1.4.11 |

## Contrast, measured

Every pair is measured in the browser from the values the page actually loaded (WCAG 2.x
formula, oklch converted to sRGB). Thresholds: 4.5 : 1 for text (WCAG 1.4.3), 3 : 1 for UI
elements such as outlines and focus rings (WCAG 1.4.11).

Below-threshold pairs and what to do:

| Pair | Status | Fix |
|---|---|---|
| `border` on `background` / `card` | accepted exception T7 | Never use `border` for anything that must be seen to operate the UI: field outlines use `input`, focus uses `ring`. |
| `destructive` on a 20 % (light) / 30 % (dark) hover tint | was below 4.5 in tokeny.md | Not used: the destructive button changes its border on hover, not its fill (C7). |
| `primary-foreground` on the hover fill `primary/90` | computed 12.88–12.96 : 1 light, 11.61–11.77 : 1 dark | passes; hover keeps the label readable (B2). |

## Changing a colour

Every value here is a start value (T1). After any change, reopen this page in both themes:
the contrast table re-measures itself. A pair that drops below its threshold blocks the change.
