# Motion

Motion confirms what the user did; it never decorates (antycharakter: efekciarski, A01).

| Rule | Source |
|---|---|
| With `prefers-reduced-motion: reduce` every duration is 0 ms, including enter and exit animations. | Q4, WCAG 2.3.3 |
| No success animation before the server has confirmed the action. Pending state shows a spinner, then the result. | Q4 |
| No page-enter animations, no parallax, no animated gradients or glow. | A01 |
| Easing: Tailwind's default `ease` curves (existing state; no decision). | existing |

To check reduced motion, turn on "Reduce motion" in your operating system or emulate it in the
browser DevTools (Rendering → Emulate CSS media feature `prefers-reduced-motion`).
