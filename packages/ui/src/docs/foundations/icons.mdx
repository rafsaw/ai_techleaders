## Sizes

| Size | Class | Where | Source |
|---|---|---|---|
| 16 px | `size-4` | default: buttons, alerts, inline with `text-body` and `text-label` | start value, proposal approved by Rafał 2026-10-21 |
| 14 px | `size-3.5` | small buttons, inline with `text-meta` | start value, proposal approved by Rafał 2026-10-21 |
| 12 px | `size-3` | extra small buttons, badges | start value, proposal approved by Rafał 2026-10-21 |

## When an icon needs a label

| Situation | What to do | Source |
|---|---|---|
| Icon next to visible text | `aria-hidden`; the text is the name | WCAG 1.1.1 |
| Icon-only button (e.g. copy link) | `aria-label` with a verb and object: "Copy public link" | WCAG 4.1.2, 2.5.3 |
| Status icon | always together with status text; the icon alone never carries the meaning | Q2, WCAG 1.4.1 |
| External link | `ExternalLink` icon plus "(opens in a new tab)" for screen readers | E02 UI/UX |

## Never used

| Icon | Why | Source |
|---|---|---|
| `Sparkles` | the generic AI symbol | A01, Z5 |
| `Star` | ratings | A03, N02 |
| `Heart`, `ThumbsUp` | community and likes | A04 |
| `Video`, `Camera`, `Mic` | sessions are text only | A06, N01 |
| Emoji instead of icons | noise; text only in the product | R02.5, A01 |
