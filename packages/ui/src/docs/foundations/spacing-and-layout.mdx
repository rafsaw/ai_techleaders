# Spacing and layout

Spacing is chosen by **relation**, not by eye: ask "what are these two things to each other?"
and take the token for that relation (T4). Every step of the 4 px scale has one relation.

| Rule | Source |
|---|---|
| Lists are dense through the row tokens only; everything else keeps the relation spacing. | K2, Z7 |
| Don't use a relation token for another relation (e.g. `gap-section` inside a panel). | T4 |
| Numeric utilities (`p-4`, `gap-2`) come from the same `--spacing` base, but prefer the named relation. | T4 |

## Widths

Every screen is checked at **320, 768 and 1440 px** (prompt, stage 5).

| Width | What changes | Source |
|---|---|---|
| 320 px | one column; page side margin `px-page-gutter` (16 px) | P-L1, proposal approved by Rafał |
| 768 px (`md`) | forms stay one column; side by side only for label and value pairs | P-L2, proposal approved by Rafał |
| 1440 px | content stays at `max-w-content`, centred (`mx-auto`) | P-L3, proposal approved by Rafał |

A page frame therefore is `mx-auto w-full max-w-content px-page-gutter`.
