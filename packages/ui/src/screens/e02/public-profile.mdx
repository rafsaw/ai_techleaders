# Public profile

`/mentors/[id]`, public kit. Source: E02 Flow 2 step 4, MD4. Every state below is a full-screen story with
the real site header. The page frame (P-SCR1) and the page title (P-SCR2) are proposals approved by Rafał; the app
has no layouts yet.

## What the screen is for

Letting a mentee judge a mentor by their work and prices, and see whether they can book.

## Built from

**Site header** and the **Detail view** pattern (Mentor profile header, Public work links, Price list, Text-only note, Not bookable notice).
