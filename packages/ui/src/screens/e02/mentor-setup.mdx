# Mentor setup

`/mentor`, signed-in kit. Source: E02 Flow 1, Flow 3. Every state below is a full-screen story with
the real site header. The page frame (P-SCR1) and the page title (P-SCR2) are proposals approved by Rafał; the app

## What the screen is for

Showing a mentor what is done, what is next and whether they can be booked.
