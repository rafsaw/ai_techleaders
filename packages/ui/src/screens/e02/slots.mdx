# Slots

`/mentor/slots`, signed-in kit. Source: E02 Flow 4. Every state below is a full-screen story with
the real site header. The page frame (P-SCR1) and the page title (P-SCR2) are proposals approved by Rafał; the app
has no layouts yet.

## What the screen is for

Publishing start times mentees can book, and removing open ones.

## Built from

**Site header**, the page's slot form (useSchemaForm, Field, Input, Button, Spinner, Alert), **Slot list**, **Slot row**. Patterns: **Form**, **Delete confirmation**.

**Add a slot** sits above **Upcoming slots** so the page's main action is visible without scrolling, even with many slots (P-SCR5, proposal approved by Rafał; the spec lists the list first). The slot form is colocated in the app (E02 UI/UX), so this story rebuilds it from package parts.
