# Profile form

`/mentor/profile`, signed-in kit. Source: E02 Flow 2. Every state below is a full-screen story with
the real site header. The page frame (P-SCR1) and the page title (P-SCR2) are proposals approved by Rafał; the app
has no layouts yet.

## What the screen is for

Creating or editing the public profile: area, description, links and the two prices.

## Built from

**Site header**, **CrudForm** with select and textarea fields (Native select, Textarea, Input). Pattern: **Form**.
