# Check email

`/sign-up/check-email`, public kit. Source: E01 Flow 2, UI/UX `/sign-up/check-email`. Every state below is a full-screen story with

## Notes

The not-sent variant follows SM-AC3 (approved 2026-10-27): *We couldn't send the email. Please try again
later.*, no cause, no countdown, no retry control, and **Back to sign-up** (it keeps `returnTo`).
This supersedes P-SCR4 (a resend body and **Sign in** as the main action). Resend through sign-in
is unchanged. Without `email` in the address the page redirects to `/sign-up` (SM-AC5).
