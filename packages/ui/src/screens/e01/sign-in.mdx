# Sign in

`/sign-in`, public kit. Source: E01 Flow 1–2, UI/UX `/sign-in`. Every state below is a full-screen story with
the real site header. The page frame (P-SCR1) and the page title (P-SCR2) are proposals approved by Rafał; the app
has no layouts yet.

## What the screen is for

Signing in with GitHub first, or with email and password, and coming back with a message when GitHub fails.

## Built from

**Site header**, **Sign-in options** (Notice, Schema form, Password field, Link button). Patterns: **Form**, **Sign-in and return**.
