# Sign up

`/sign-up`, public kit. Source: E01 Flow 2, UI/UX `/sign-up`. Every state below is a full-screen story with
the real site header. The page frame (P-SCR1) and the page title (P-SCR2) are proposals approved by Rafał; the app
has no layouts yet.

## What the screen is for

Creating an email account, with the password rule and the no-reset warning (N03) shown before typing.

## Built from

**Site header**, **Notice**, **Schema form**, **Password field**, **Link button**. Pattern: **Form**.
