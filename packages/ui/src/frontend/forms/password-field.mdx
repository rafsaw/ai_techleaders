# Password field

`import { PasswordField, PASSWORD_HINT } from "@devmentor/ui/frontend/forms/PasswordField"`

Public kit (F3): a text field for passwords with the AD6 rule as a hint and a toggle that shows
the typed phrase.

## 1. What it is for

A password field lets a visitor type a long phrase safely, see the length rule before typing,
and check what they typed.

## 2. When to use

- `/sign-up` (new password), `/sign-in` (current password), `/confirm-email` (the password of the account, E01 Flow 2).

## 3. When not to use

| Situation | Use instead | Source |
|---|---|---|
| Any other short value | `TextField` | — |
| A signed-in page | `Input type="password"` + `Field` | Q1 |
| Password reset | nothing: not in 1.0 | N03 |

## 4. Anatomy

| Part | Required | Notes |
|---|---|---|
| Label | yes | *Password* by default |
| Input | yes | as `TextField`, `type="password"`, no autocapitalise, no spell check |
| Show toggle | yes | 36 × 36 px button inside the input, eye icon, `aria-pressed` (P-PF1, proposal approved by PO(Rafał)) |
| Hint | default | *Use a short phrase of at least 15 characters.* (AD6); pass `hint={null}` on sign-in |
| Error | when invalid | as `TextField` |

## 5. Variants

| `autoComplete` | When | Source |
|---|---|---|
| `new-password` | sign-up: password managers offer a generated one | E01 AD6 (password-manager support), WCAG 1.3.5 |
| `current-password` (default) | sign-in, confirm email | E01 AD6 |

## 7. Behaviour and accessibility

- The toggle is a real button with a fixed name, *Show password*, and `aria-pressed` for its state (WAI-ARIA APG toggle button); it does not submit the form.
- Paste and password managers work: no `onPaste` blocking, `autoComplete` set (E01 AD6, WCAG 3.3.8).
- The value is never trimmed or changed (E01 `passwordSchema`).
- Tab order: input, then toggle (story *Long content, narrow* tests it and the 24 × 24 px minimum target).

## 8. Content

- Label: *Password*.
- Hint: the length rule only, no composition rules (AD6).
- Error: what to do (*Use at least 15 characters*); a server refusal (*This password is too common. Use a short phrase.*) lands on this field.

## 10. API

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | `"Password"` | visible label |
| `hint` | `ReactNode` | `PASSWORD_HINT` | `null` hides it |
| `errors` | `readonly string[]` | — | messages |
| `autoComplete` | `"current-password" \| "new-password"` | `"current-password"` | password-manager hint |
| …rest | `<input>` props | — | `name`, `value`, `onChange`, `onBlur`, `disabled` |

## 11. Code

```tsx
<PasswordField name="password" autoComplete="new-password" />
```

From the product (`/sign-in`), through `SchemaForm`:

```tsx
{ name: "password", label: "Password", type: "password", hint: null }
```
